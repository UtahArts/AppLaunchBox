# App Launch Box

アプリ・フォルダー・Webページをプリセットにまとめて起動する、Windows向けランチャーです。

## ダウンロード
[最新版インストーラー 3.1.6](https://github.com/UtahArts/AppLaunchBox/releases/download/v3.1.6/AppLaunchBox-Setup-3.1.6.exe) / [リリース一覧](https://github.com/UtahArts/AppLaunchBox/releases)

Windows 10・11 x64向けです。3.1.6から必要な.NET実行環境を同梱し、別途Runtimeの導入が不要になりました。Windows 10ではすりガラス項目を非表示にします。Windows 10実機での動作確認は未実施です。

## 3.1.6の変更
OneDriveのクラウド属性をリンクと誤判定する処理を修正しました。リンク・ジャンクションの保護を維持し、保存先移行時のファイル照合を追加しています。既存の保存先は変更しません。

本体・インストーラーのビルド、依存248件、PowerShell 5.1構文を確認済みです。実際のOneDriveサービス、今回のインストーラー導入・更新・削除の実動作テストは未実施です。
