# App Launch Box
アプリ・フォルダー・Webページをプリセットにまとめて起動する、Windows向けランチャーです。

## ダウンロード
[最新版インストーラー 3.1.9](https://github.com/UtahArts/AppLaunchBox/releases/download/v3.1.9/AppLaunchBox-Setup-3.1.9.exe) / [リリース一覧](https://github.com/UtahArts/AppLaunchBox/releases)

Windows 10・11 x64向けです。必要な.NET実行環境を同梱します。Windows 10ではすりガラス項目を非表示にします。Windows 10実機での動作確認は未実施です。

## 3.1.9の変更
起動失敗の名前・アイコン・理由・対処方法を一覧表示し、失敗したアイコンを赤く光らせます。エラー画面を閉じなくても一括起動を続行します。「ログをコピー」と14日間の診断ログ保存を追加しました。表示例で見た目は確認済みですが、実アプリの連続起動・コピー・記録・保持期限の実動作は未検証です。

## 3.1.8から継続している対策
更新ファイルの実行直前の再照合と、起動までの書換え防止を追加しました。同じ安全対策のローカル修正で、更新23項目・導入／更新／削除14項目・基本／復旧20グループが通過しています。3.1.9の本体・インストーラーのビルドと依存248件の照合が成功しています。

電子署名の証明書は未取得で、EXEは未署名です。Windows 10実機・実際のOneDrive・ディスク満杯・電源断・更新UIから再起動までの一連の実動作は未検証です。

## 機能
一括起動・終了、起動中一覧、ブラウザのお気に入り登録、スタートアップ管理、配色・画像カスタマイズ、バックアップ、チュートリアル、確認後の自動更新と更新中の進捗表示に対応しています。
