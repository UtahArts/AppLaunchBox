# App Launch Box

アプリ・フォルダー・Webページをプリセットにまとめて起動する、Windows向けランチャーです。

## ダウンロード

[最新版のインストーラー](https://github.com/UtahArts/AppLaunchBox/releases/latest/download/AppLaunchBox-Setup-3.1.5.exe) / [リリース一覧](https://github.com/UtahArts/AppLaunchBox/releases)

公開版3.1.5には、バックアップ・設定容量制限の統一、移動履歴の修正、一括起動の中止・再試行・結果一覧、右パネルのクリック・キーボード操作、不正なリンクをスキップする一括登録が含まれます。

3.1.5ではポートフォリオリンク、終了できなかった場合の理由表示、エクスプローラーのフォルダアイコンを追加しています。
